Rig Controllers 2.3.0 — установка
Moho Pro 14.4, Windows
==================================================

ЧТО В АРХИВЕ

  scripts\tool\mk_rig_controllers.lua            сам инструмент (один файл)
  scripts\tool\mk_rig_controllers*.png           значок инструмента
  scripts\ScriptResources\MK_RigControllers\icons\  значки кнопок панели
  README_RU.md, README_EN.md                     описание и руководство
  docs\img\                                      картинки к руководству
  INSTALL_RU.txt, INSTALL_EN.txt                 эта инструкция


УСТАНОВКА С НУЛЯ

  1. Сохраните работу и закройте Moho.
  2. Откройте папку пользовательского контента Moho.
     В Moho: Help → Open Custom Content Folder.
     Если папка ещё не задана: Help → Set Custom Content Folder.
  3. Скопируйте папку scripts из архива в папку пользовательского контента.
     Внутри неё уже может быть папка Scripts. Тогда согласитесь на объединение папок.
  4. Запустите Moho.
  5. Выберите костный слой. В панели Tools, в группе Other, появится
     значок джойстика. Это Rig Controllers.

  Проверка: Риг → Настройки и справка… внизу окна написано «Rig Controllers 2.3.0».


ОБНОВЛЕНИЕ С ВЕРСИИ 2.0, 2.1 ИЛИ 2.2

  1. Сохраните работу и закройте Moho.
  2. Сделайте копию старых файлов в любое место ВНЕ папки Scripts:
       Scripts\Tool\mk_rig_controllers.lua
       Scripts\ScriptResources\MK_RigControllers\
     Внутри Scripts копию оставлять нельзя: Moho загрузит её как второй инструмент.
  3. Скопируйте папку scripts из архива с заменой файлов.
  4. Только после версии 2.2: удалите три файла, они больше не нужны.
       Scripts\ScriptResources\MK_RigControllers\mk_rig_workspace.lua
       Scripts\ScriptResources\MK_RigControllers\mk_rig_corrections.lua
       Scripts\ScriptResources\MK_RigControllers\mk_rig_en.lua
     Если их оставить, ничего не сломается.
  5. Запустите Moho.

  Старые документы открываются без переделки.
  Документ из версии 2.0: Риг → Обновить старые контроллеры (2.0).
  Перед работой над важным проектом сохраните его копию.


ЯЗЫК ИНТЕРФЕЙСА

  Риг → Настройки и справка… → Язык интерфейса.
  «Как в Moho» берёт язык самой программы. После смены языка выберите
  другой инструмент и вернитесь к Rig Controllers.


УДАЛЕНИЕ

  Закройте Moho и удалите:
    Scripts\Tool\mk_rig_controllers.lua и три файла mk_rig_controllers*.png
    Scripts\ScriptResources\MK_RigControllers\
  Документы с контроллерами продолжат проигрываться и рендериться.


ЕСЛИ ЧТО-ТО НЕ ТАК

  Значка инструмента нет.
    Выберите костный слой или слой внутри него. Инструмент показывается только там.
    Проверьте, что файл лежит в Scripts\Tool пользовательского контента.

  На панели текстовые кнопки вместо значков.
    Не найдена папка icons. Скопируйте папку ScriptResources из архива ещё раз.
    Инструмент работает и с текстовыми кнопками.

  Панель не помещается по ширине.
    Сделайте окно Moho шире. Все команды также есть в меню «Позы», «Группа» и «Риг».

  В списке инструментов два Rig Controllers.
    В папке Scripts осталась копия старого файла. Уберите её из Scripts.

  Не видно служебных костей.
    Так и задумано. Показать их: Риг → Показать служебные кости.
