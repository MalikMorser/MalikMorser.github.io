RIG CONTROLLERS 2.1 для Moho Pro 14.4 (Windows) — КАК УСТАНОВИТЬ ОБНОВЛЕНИЕ
==========================================================================

В этой папке:
  Rig_Controllers_2.1_for_Moho_14.4.zip      — русская версия
  Rig_Controllers_2.1_EN_for_Moho_14.4.zip   — английская версия (English edition)
Ставьте ОДНУ из них: у них одинаковые файлы, вторая просто заменит первую.
Риги, анимация и данные у обеих версий полностью совместимы.


1. ПЕРЕД ОБНОВЛЕНИЕМ
--------------------
1. Сохраните и закройте все проекты в Moho.
2. Сделайте копию важных проектов с контроллерами (на всякий случай).
3. Если Windows пометила архив как скачанный из интернета: правый щелчок
   по архиву → «Свойства» → флажок «Разблокировать» → OK.
4. Распакуйте архив: правый щелчок → «Извлечь все…» → «Извлечь».


2. УСТАНОВКА ПОВЕРХ СТАРОЙ ВЕРСИИ
---------------------------------
Способ 1 — установщиком Moho:
1. Запустите Moho Pro 14.4.
2. Scripts → Install Script…
3. Выберите папку scripts внутри распакованной папки «Rig Controllers 2.1».
4. На вопрос о замене файлов ответьте «Да».
5. ОБЯЗАТЕЛЬНО полностью закройте Moho и запустите снова: новые значки
   и новый код Moho загружает только при запуске.

Способ 2 — вручную:
1. В Moho: File → Open Custom Content Folder, затем закройте Moho.
2. Скопируйте папку scripts из «Rig Controllers 2.1» в открывшуюся папку,
   объединяя папки и заменяя файлы.
3. Запустите Moho.

Проверка: Tools → группа Other → Rig Controllers. На панели инструмента
рядом со списком контроллеров появился список групп и маленькие кнопки
(+, стрелки, карандаш, корзина).


3. ОБНОВЛЕНИЕ СТАРЫХ РИГОВ (1.x–2.0)
------------------------------------
Старые риги открываются и работают как раньше. Чтобы перевести их на новые
кости-ромбики:
1. Откройте проект, выберите костный слой с контроллерами, инструмент
   Rig Controllers.
2. Smart Bones (кнопка с молнией) → «Обновить контроллеры до 2.1
   (кости-ромбики)».
3. Вся анимация переносится на ромбики: те же кадры, значения и
   интерполяция. Драйверы становятся скрытыми. Отмена — один Ctrl+Z.
4. Сохраните проект.
Обновление делается для каждого костного слоя с контроллерами отдельно.


4. ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------
• Старые значки или нет новых кнопок — Moho не был перезапущен.
• Ошибка «module not found» или пропали кнопки — установлена не вся папка
  scripts; установите её заново целиком.
• Файлы проекта, обновлённые до 2.1, открываются и в старых версиях
  плагина, но ромбики там будут обычными костями, а группы не видны.
  Поэтому обновляйте плагин на всех компьютерах, где работаете с проектом.


ЧТО НОВОГО В 2.1
----------------
• Ромбик контроллера — настоящая кость Moho (точка-кость нулевой длины).
  Ключи анимации — ключи её перемещения на Timeline: их можно двигать,
  копировать, удалять и менять интерполяцию штатными средствами.
• Выделенный контроллер красный, как выделенная кость Moho.
• Кости-драйверы служебные и всегда скрыты — на холсте только ромбики.
  Их ключи плагин строит сам из ключей ромбика, файл работает и без плагина.
• Группы контроллеров (Head, Body…): на холсте только контроллеры
  выбранной группы. Кнопки: + новая группа, в группу, из группы,
  переименовать, удалить. Ctrl+A — выбрать всю группу.
• Команда обновления старых ригов с переносом всей анимации.
• Исправлено: при скрытых костях-драйверах ключи контроллера
  не были видны на Timeline.
