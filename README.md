# React + Vite Project

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## Deployment Instructions (Публикация)

### 1. Initialize Git (Инициализация Git)

Open your terminal in the project folder and run:

```bash
git init
git add .
git commit -m "Initial commit"
```

### 2. Push to GitHub (Загрузка на GitHub)

1.  Go to [GitHub.com](https://github.com) and create a new repository.
2.  Copy the commands shown in the "…or push an existing repository from the command line" section.
3.  Run them in your terminal:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

### 3. Deploy to Vercel (Публикация на Vercel)

The easiest way to deploy a Vite app is using Vercel:

1.  Go to [Vercel.com](https://vercel.com) and sign up/login with GitHub.
2.  Click **"Add New..."** -> **"Project"**.
3.  Import your GitHub repository.
4.  Vercel will automatically detect Vite. Just click **Deploy**.

Your site will be live in less than a minute!

## Development

To run the project locally:

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```
